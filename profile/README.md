# Firmafakta

Swedish company data from the registers of SCB, Bolagsverket and PRV. Find companies by industry,
place and size, look up any company by organisation number, and export the list, on the web or
from your AI assistant.

- [firmafakta.se](https://firmafakta.se/en/): the service, free to try
- [firmafakta-mcp](https://github.com/firmafakta/firmafakta-mcp): connect Claude, ChatGPT, Cursor
  or VS Code to the data over MCP
